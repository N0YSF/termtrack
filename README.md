# TermTrack

A small terminal-based task tracker built for personal use.

The project started as a simple way to keep track of university
tasks without opening a separate application.

## Features

- Add tasks
- List tasks
- Mark tasks as completed
- Store tasks locally as JSON

## Requirements

- Python 3.x

No external Python packages are required.

## Usage

Add a task:

```bash
python3 termtrack.py add "Finish database assignment"
